# Hosted comparison verification · November 15, 2026

In [DiffMD](https://diffmd.web.app/), open **Home → Read encounter → Load notes in Compare → Compare notes**. The browser submits an empty request. The web service passes the bundled pair’s ID and SHA-256 fingerprint to the private worker. Both services verify the fixture identity. The web service grounds each returned name at an exact source offset and checks each side against the authored medication lists before publishing the result. Rules identify regimen changes, including changes in dose. If inference fails or returns an incomplete extraction, the browser labels its rules fallback. Edited and alternate notes are compared in the browser.

- A fresh Cloud Run request on `diffmd-encounter-00003-qas` returned six medication mentions from one fictional pair in 25.6 seconds. Earlier contained Lisinopril, Metformin, and Aspirin. Later contained Lisinopril, Metformin, and Atorvastatin. The dose change from Lisinopril 10 mg daily to 20 mg daily is derived from the two rule-checked source excerpts. Aspirin’s absence from the later note does not establish that it was stopped.
- The worker ran pretrained `ggml-org/Qwen3.5-4B-GGUF`, revision `8d43d974efc48399cb58957ad49c8b26bf5a109c`, Q4_K_M, with no adapter. An anonymous worker health request returned HTTP 403. The same revision produced an audio draft from the existing sample in 26.9 seconds with no transcription or draft coverage flags.
- Chrome checks at 1440 px with keyboard and at 768 and 390 px with touch showed the three differences, source excerpts, focus on the result, a labeled cache hit, and no overflow. Editing a note made no comparison POST. A nonempty request was rejected with HTTP 400, and an injected timeout displayed the rules fallback. Repeated browser runs check the interface on the same case.
