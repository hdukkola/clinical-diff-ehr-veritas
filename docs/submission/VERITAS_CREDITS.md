## How the main workflow works

The live workspace starts with an empty patient list. Reviewers create cases using non-identifying references and supply de-identified notes. Browser rules compare the notes. Reviewers inspect the excerpts, flag questions and can export a follow-up. On their own synced case, invited users can transcribe up to 30 seconds of permitted, de-identified English audio. The Cloud Run worker runs Whisper base.en. The reviewer edits the transcript, adds it to a note draft and saves it separately. [Live workspace](https://diffmd.web.app/) · [Transcription and account setup](../../README.md)

In the private Qwen workflow, the backend verifies each returned medication name against its source, then deterministic code compares the results. Private tests used fictional notes, snapshots and a scripted encounter. The hosted smoke tests used one bundled note pair and one bundled recording. [Local inference setup](../../fresh-backend/README.md) · [Hosted comparison](HOSTED_COMPARE_SMOKE.md) · [Private encounter audio](ENCOUNTER_AUDIO_SMOKE.md)

The encounter drafting experiment passes the fixed fictional transcript ID to Qwen and renders the selected turns as verbatim excerpts. The browser marks missing sections for review and links the reviewer back to the full transcript. This workflow was verified with the local MLX conversion. [Encounter API and validation](../../src/app/api/encounter-note/route.ts) · [Evidence selection and model identity](../../src/lib/encounter-inference.ts) · [Draft and source links](../../src/components/EncounterNoteDraft.tsx)

## Results we measured

| Run | Measured result | Source |
| --- | --- | --- |
| **Local Qwen3.5-4B medication-name extraction** | 40 public synthetic notes, 60 reference names. Empty baseline: 0 matches, 0 unmatched predictions and 60 missed references. Qwen: 49 matches, 11 unmatched predictions and 11 missed references, with **81.7% exact-name precision and 81.7% recall**. All 40 responses parsed. The scorer counted “Advil” versus “ibuprofen” as one unmatched prediction and one missed reference. | [Frozen rules and interpretation](https://github.com/hdukkola/clinical-diff-ehr-veritas/blob/38f36e43b7a33f2abb7353fb821e3b5f74ee7ea7/fresh-eval/README.md) · [Saved case-level results](https://github.com/hdukkola/clinical-diff-ehr-veritas/blob/38f36e43b7a33f2abb7353fb821e3b5f74ee7ea7/fresh-eval/results.json) |
| **Deterministic engineering checks** | **50,000/50,000 passed** on the verified workspace commit, including 30,000 structured and 20,000 note-based synthetic comparisons. These are generated test cases for the rules engine, with zero hosted model requests. | [Reproducible cases and assertions](../../src/lib/diff-scale.test.ts) · [Recorded verification](https://github.com/hdukkola/clinical-diff-ehr-veritas/commit/f2314ed) |
| **Transcript-to-note drafting** | A separate local three-case unadapted 4B screen found one factual source mix-up. The injection probe also echoed the attack text. The team has not released this workflow or established its clinical accuracy. | [Saved synthetic inputs and local model outputs, November 15, 2026](NOTE_DRAFT_BASELINE.json) |
| **Source-linked encounter draft smoke test** | The local Qwen selected turns `t04`, `t05` and `t06` from one scripted encounter. It omitted the earlier medication history (`t02` and `t03`). Browser checks at 390, 768 and 1440 px displayed the selected verbatim excerpts, flagged the draft as partial and let the reviewer open the source. This is one scenario tested at three widths. | [Recorded smoke test, November 15, 2026](ENCOUNTER_DRAFT_SMOKE.md) |
| **Cloud Run bundled note comparison** | One fresh call on one fictional pair returned all six expected literal mentions in 25.6 seconds. The app showed two mention differences and one rule-derived dose difference. | [Hosted comparison smoke record](HOSTED_COMPARE_SMOKE.md) |
| **Cloud Run audio note-taker** | One fictional recording and three fresh cloud attempts. The first timed out. The second and third returned four source-linked excerpts in 21.2 and 26.9 seconds, preserving the known dose, uncertainty, and planned follow-up. | [Artifact identity and observed draft](ENCOUNTER_AUDIO_SMOKE.md) |
| **Live recording release checks** | The private Whisper worker transcribed one nonclinical QA recording. The live Firebase endpoint rejected a signed-out request and a forged token. An automated UI test with mocked services covered consent, editing, review confirmation and explicit saving. A full signed-in upload and save on Firebase remains unverified. | [Release handoff](../../COMMUNICATION.md) · [UI regression check](../../src/app/page.test.tsx) |

The 40-note evaluation measures literal extraction from single notes with generated labels. It does not measure treatment decisions, clinical reconciliation accuracy, or patient outcomes. A recorded count applies only to the workload named in its row. The team should demonstrate the workflow and explain the source check, deterministic comparison, human review and scoring in its own words.
